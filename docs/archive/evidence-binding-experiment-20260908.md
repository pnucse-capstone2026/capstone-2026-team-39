## 1. 무엇을 바꾸었나

- [`scripts/rag/evidence_binding_experiment.py`](../../scripts/rag/evidence_binding_experiment.py)
  는 서비스에 연결하지 않은 실험 함수다. 기존 C2 거부를 승격하지 않고,
  기존 통과 claim에 추가적인 **단일 근거 단위 검사**를 적용한다.
- [`scripts/evaluate_evidence_binding_experiment.py`](../../scripts/evaluate_evidence_binding_experiment.py)
  는 고정된 Shadow 진단 입력과 합성 문장을 사용한다. 임의 입력 파일, API 키,
  생성 옵션을 받지 않는다. 새 디렉터리에 JSON·CSV·manifest를 생성한다.
- [`tests/test_evidence_binding_experiment.py`](../../tests/test_evidence_binding_experiment.py)
  에 신규 unittest 26개를 추가했다. 합성 조합 검사는 subtest로 수행한다.

검증기의 원인 가설은 실제로 재현됐다. 기존 C2는 인용 전체의 숫자·단어 집합을
합쳐 검사하므로, 다른 강좌 날짜나 다른 상담실 번호도 통과시킬 수 있다.
또 기존 C1 분리기는 연·월 약식 범위에서 문장을 끊고 짧은 뒷부분을 버렸다.

실험 방식:

1. 공백을 합치기 **전의 원문 행/문장 경계**를 복원하고 인용 구간과 교차한다.
   인용이 원문에 있는지 먼저 확인한다. 좌표는 NFKC·공백 정규화 원문 기준으로
   명시하며, 각 구간에 SHA-256을 기록한다. 여러 구절을 이어붙여 근거로 쓰지 않는다.
2. 숫자와 가능/불가·필수/면제 같은 방향 표현은 행 선택 점수에서 제외한다.
   잘못 가져온 값이 있는 행으로 검증기가 끌려가지 않도록 한다.
3. 단어가 가장 잘 맞는 행이 claim의 값·관계 표현을 단독으로 뒷받침하는지 검사한다.
   전화번호 전체, 월·일 조합, 연도, 수량 단위, 조건/부정 표현도 별도로 확인한다.
4. 제목/절의 숫자를 무제한으로 빌리지 않는다. 명시된 연도·회차 범위만 제한적으로
   허용한다. 이 때문에 타당한 제목/여러 행 상속을 거부할 가능성도 있다.
5. 별도 날짜 분리 함수는 날짜 구간의 마침표 위치를 보호하고 최소 길이 필터나
   긴 문장 자르기를 사용하지 않는다. 날짜의 실제 달력 유효성을 검증하는 함수는 아니다.

반환값은 `supported`나 최종 답변이 아닌 `scope_gate_passed`다. **검사 통과는
문장의 의미적 타당성 보증이 아니다.** 기존 검색/생성 prompt/후처리/Judge는 불변이다.

## 2. 구성요소 실험 결과 — 서비스 GFC 아님

모든 기대 판정은 AI가 원문/합성 문장으로 만든 개발용 판정이다. 사람 label이나
독립 테스트셋 정답이 아니다. 이미 본 Shadow 진단에 맞춰 작성한 검사이므로
표의 숫자를 전체 서비스 정확도나 일반화 성능으로 해석하면 안 된다.

| 검사 집합 | 수 | 기존 C2 오답 통과 | 실험 오답 통과 | 기존 정답 보존 | 실험 정답 보존 |
|---|---:|---:|---:|---:|---:|
| 이전 원문 기반 반례·대조 | 6 | 2/4 | 0/4 | 2/2 | 2/2 |
| 이름·행 순서 변경 등 합성 조합 | 55 | 30/30 | 0/30 | 25/25 | 25/25 |
| 추가 스트레스 검사 | 4 | 3/3 | 3/3 | 1/1 | 0/1 |
| **전체** | **65** | **35/37** | **3/37** | **28/28** | **27/28** |

이전 반례의 GSAT/NCS 일정 혼동, 성평등/인권 상담실 번호 혼동은 차단하고
올바른 값은 유지했다. 합성 조합은 일정·전화번호·금액·인원·예약 의무·지급 조건에
영문/한글 명칭과 행 순서 변경을 적용했다. 숫자의 자리 조합, 연도와 날짜 연결,
호실을 금액으로 전용, 제목 숫자 유출, 부정 표현 검사도 포함했다.

하지만 `component_gate_passed=false`다. 뒤늦게 추가한 어려운 반례도 전체 집계에
포함했으며, 실패 4건을 숨기거나 통과 기준을 낮추지 않았다.

### 동결 후 발견 — 남은 실패

| probe_id | 결과 | 남은 문제 |
|---|---|---|
| `flattened_subjects` | 오답 통과 | 한 줄로 평탄화된 두 기관의 번호는 여전히 섞일 수 있음 |
| `same_row_columns` | 오답 통과 | 한 행의 접수일/발표일을 서로 바꿔도 날짜 집합만으로 구분 못 함 |
| `condition_reversal` | 오답 통과 | `평가 통과`를 `평가 미통과`로 바꾸어도 조건 단어 존재만으로 구별 못 함 |
| `valid_cross_row` | 정답 거부 | 대상 이름과 인원이 별도 행에 있으면 정상적인 상속 관계도 차단함 |

원리적 한계: 행 분리만으로는 대상–속성–값–조건의 관계를 모두 복원할 수 없다.
단어 겹침을 의미 판단으로 취급하지 않는다. 이 실험을 동결 C2 또는 서비스에
연결하지 않았으며, 안전성 개선을 이유로 생성 성능이 향상됐다고 발표하지 않는다.

  차단 audit hook 안에서 실행했다. 미승인 C2 호출 차단 검사의 argparse 오류 메시지는
  예상된 출력이다. 전체 저장소 unittest가 통과했다고 주장하지 않는다.

  막혔다. 제품 코드 수정으로 우회하지 않았다. 로컬 stub 실행 권한을 받은 후
  `test_rag_generators.py` 20개가 성공했다(skip/실패/오류 0). 외부 DNS/통신 및 보호
  파일 차단은 유지했다. 최종 관련 테스트는 74+20=94개 성공이다.
